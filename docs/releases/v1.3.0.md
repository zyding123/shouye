# 守夜 1.3.0

## 新增：支持 Intel Mac

安装包改为**通用二进制（Universal 2）**：同一个 `.app` 里同时包含 Apple Silicon 与 Intel 的代码，
系统会自动选用原生架构运行。**功能、界面、权限行为与之前完全一致。**

## 安装包变化

| 项目 | 变化 |
|---|---|
| 文件名 | `Shouye-1.2.1-macOS-arm64.*` → `Shouye-1.3.0-macOS-universal.*` |
| App 体积 | 约 680 KB → 约 1.0 MB（多了一份 Intel 代码） |
| 最低系统 | 仍为 macOS 13.0 |
| 权限行为 | 不变（仍只需那一条范围极窄的 `disablesleep` 规则） |

## 验证情况

- **Apple Silicon**：原生运行，`--lid` / `--displays` / `--lockstate` 正常
- **Intel**：在 Apple Silicon 机器上通过 **Rosetta 2 实际执行 x86_64 切片**，
  三个诊断命令的输出与原生**完全一致**；看门狗二进制同样含双架构
- **未在真实 Intel 硬件上测试**——如果你在 Intel Mac 上遇到问题，
  请开 issue 告知机型与系统版本

## 升级方式

旧版可以直接覆盖安装；升级前请先从菜单退出旧版（会恢复系统默认），
避免在合盖远程使用状态下突然断连。
