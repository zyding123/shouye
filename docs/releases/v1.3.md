# 守夜 1.3

## 这一版只改了一个默认值

「接外接显示器时暂停」由默认**关闭**改为默认**开启**。

原因：新用户第一次接上外接显示器时，桌面场景下让 Mac 恢复正常休眠才符合预期；
否则容易变成"我插了显示器，它还在强制不休眠"。拔掉显示器后会自动恢复守护。

## 不受影响的行为

- **合盖 + 外接显示器 → 跳过锁屏与息屏**：这条与开关无关，始终生效。
  所以即使把这个开关关掉，插着外接屏合盖也不会被锁屏。
- **已经手动改过这个设置的人，保持你自己的选择**，不会被这次默认值改动覆盖。
- 想要在桌面场景继续强制不休眠：菜单里取消勾选「接外接显示器时暂停」即可。
