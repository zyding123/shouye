首个可直接下载安装的版本，无需编译。

**支持：Apple Silicon（M 系列）Mac，macOS 13 及以上。暂不支持 Intel Mac。**

### 下载与安装

- 推荐下载 `Shouye-1.1-macOS-arm64.dmg`，打开后将「守夜.app」拖到 Applications。
- 也可下载 `Shouye-1.1-macOS-arm64.zip`，解压后将 App 移到「应用程序」。
- `Source code` 是 GitHub 自动生成的源码包，普通安装请选择上面的 DMG 或 ZIP。
- 附带 `INSTALL.txt` 和 `SHA256SUMS.txt`，可查看安装说明或核对下载文件。

### 首次打开

采用 ad-hoc 签名，尚未使用 Developer ID 证书及 Apple 公证。若系统拦截，请先尝试打开，再按 [Apple 官方说明](https://support.apple.com/102445)到「系统设置 → 隐私与安全性」允许该 App 运行。首次使用需要一次性管理员授权；预编译包无需安装 Xcode 或 Homebrew。

### 主要修复

- 开启、恢复休眠均回读确认；失败不再误报成功，保留恢复重试。
- 加固一次性权限授权，移除用户可改写的特权安装脚本。
- 看门狗采用独立名称，增加就绪确认、恢复重试和串行交接。
- 锁屏需要确认会话状态；定时器支持菜单及模态模式。
- 修复启动重试、延迟息屏、授权修复和登录启动问题。
